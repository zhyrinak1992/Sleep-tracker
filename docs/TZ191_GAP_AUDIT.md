## Яндекс Smart Home: технический план и текущая реализация

Официальный API Яндекса предоставляет:
- GET https://api.iot.yandex.net/v1.0/user/info — список комнат и устройств.
- GET https://api.iot.yandex.net/v1.0/devices/{device_id} — состояние устройства.
- Для чтения использовать только OAuth scope iot:view. Не запрашивать iot:control.
- Проверять, предоставляет ли конкретный датчик retrievable-свойства temperature и humidity.
- API текущего состояния не гарантирует архивную телеметрию. Sleep Tracker должен сам сохранять локальные snapshots с timestamp, устройством, комнатой, единицами и значением.
- Отсутствующие измерения не превращать в нули и не интерполировать.

Официальные источники:
- https://yandex.ru/dev/dialogs/smart-home/doc/ru/concepts/platform-protocol
- https://yandex.ru/dev/dialogs/smart-home/doc/ru/concepts/platform-user-info
- https://yandex.ru/dev/dialogs/smart-home/doc/ru/auth/how-it-works
