# Аудит соответствия Sleep Tracker утверждённому ТЗ v191

**Нормативный источник:** `Техническое_задание_Трекер_сна_актуальное_191.xlsx`, версия 191 от 22.11.2026.  
**Проверяемая ветка:** `feature/unified-achievements`.  
**PR:** #123, черновой.  
**Правило:** отклонённый пункт №6 не реализовывать; не добавлять функции вне v191.  
**Важно:** наличие кода или успешного CI не означает проверку на реальном iPhone.

## Статусы

- **Реализовано в исходниках** — сценарий найден и покрыт проверками на уровне кода/тестов, если это указано.
- **Частично** — реализована только часть требований или не хватает критериев/экранов.
- **Не реализовано** — требуемый сценарий в текущей ветке не найден.
- **Ожидает iPhone** — код есть, но реальное поведение iOS/HealthKit/микрофона/AltStore не подтверждено.
- **Открыто по решению** — исходное ТЗ оставляет параметр неопределённым; не подставлять произвольное значение.
- **Не входит** — пользователь явно отклонил требование.

## Подтверждённые исправления текущего прохода

1. Резервный экспорт приведён к решению v191: новый файл не требует отдельного пароля; манифест и SHA-256 остаются. Импорт прежних зашифрованных файлов сохранён для совместимости.
2. В дневнике, заметках, аналитике, отчётах, здоровье и расчёте рекордов сняты искусственные ограничения в 500–10 000 ночей: для экранов, которым нужна вся история, используется запрос без SQL LIMIT.
3. Добавлен тест, проверяющий получение полной истории сверх стандартной страницы.
4. Проверено реальное объединение SQLite: локальные конфликты сохраняются, отсутствующие записи архива добавляются; совпадающее аудиособытие не должно перезаписывать локальную карточку.

## Открытые вопросы, которые нельзя решать догадкой

- **Окончание ночных повторных проверок:** решение v191, лист «Решения и границы», пункт 25, оставляет время открытым. В коде сейчас есть слот 06:00, но считать его утверждённым нельзя. Не менять границу на другое время без решения пользователя.
- **Автоматическое определение сна без Apple Watch:** подтвердить реальную доступность и точность на iPhone; не имитировать измерения.
- **Формула SleepScore:** применять только утверждённые веса/правила и маркировать оценочный характер.
- **Проверки на физическом iPhone:** HealthKit, фоновые аудиосессии, уведомления, Яндекс Smart Home, обновление и AltStore-переподписание не могут быть подтверждены только CI.

## Критерии завершения

Пункт считается закрытым только когда:
1. Требование из v191 сопоставлено с экраном/сценарием и конкретным исходным кодом.
2. Есть тест логики и/или миграции для проверяемого сценария.
3. Нет потери пользовательских данных, подмены отсутствующих значений или несанкционированного перезаписывания.
4. CI успешно завершён на актуальном коммите.
5. Для функций, зависящих от iOS/устройства, отдельно отмечено подтверждение на физическом iPhone.

PR #123 остаётся черновым. В `main` изменения не переносятся.
