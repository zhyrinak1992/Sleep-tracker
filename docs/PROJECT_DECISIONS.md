# Зафиксированные решения проекта Sleep Tracker

Версия записи: 0.9 (21 ноября 2026)

Все решения ниже утверждены и должны сохраняться в следующих версиях исходников и документации. Изменять их можно только после отдельного согласования.

## Идентификация
- Название: Sleep Tracker.
- Постоянный iOS Bundle ID: `ru.sleeptracker.app`. Не менять между сборками и обновлениями.

## Платформа и процесс
- Основная разработка ведётся на Windows.
- Стек: Flutter/Dart для интерфейса и общей логики; Swift для нативных iOS-функций, включая HealthKit и аудиосессии.
- Пользователь не должен самостоятельно писать код или разбираться в реализации. Ассистент готовит и изменяет проект; от пользователя требуются только необходимые действия для установки и проверки.
- Mac у пользователя нет и не планируется. Не делать покупку Mac условием проекта. Для iOS-сборки использовать подходящий облачный macOS build pipeline, если локальная сборка на Windows невозможна.

## Установка и обновление
- Для установки и переподписания на iPhone выбран AltStore.
- Пользователь согласен подключать Windows-компьютер для обновления/переподписания.
- SideStore больше не является выбранным каналом установки проекта. Не возвращаться к его настройке без отдельной просьбы.
- Не тратить установки на пустые или заведомо промежуточные макеты. Перед первой установкой выполнить согласованные критерии готовности и проверить обновление поверх существующей установки с сохранением данных.

## Данные и архитектура
- Основное хранение — локально на устройстве, SQLite. Обязательное облако не требуется.
- Данные должны переживать штатные обновления приложения.
- Резервное копирование и перенос на другой iPhone — через экспорт/импорт файла в приложение «Файлы».
- Не генерировать отсутствующие показатели сна, фазы или события; показывать только фактически полученные данные.
- Аудиофрагменты событий хранить 7 дней; удаление аудио не должно удалять историю события и статистику.

## Уточнения по утверждённому ТЗ v258 (25 ноября 2026)

- Нормативный объём работ — книга ТЗ v258 от 23.11.2026: базовые требования v191 плюс согласованные дополнения 192–218. Более поздние заметки разработки не добавляют требований без явного согласования.
- Пункт «Цели и режим сна» отклонён. Не добавлять постоянные цели, расписание, будильники или напоминания о соблюдении режима.
- Время окончания повторных ночных проверок оставлено открытым. Не закреплять 03:00, 06:00 или другое время по догадке.
- Новые ручные переносимые архивы создавать в формате .sleepbackup без отдельного пароля; целостность проверять манифестом и SHA-256. Решение v256 от 23.11.2026 заменяет более раннее решение v210 о парольном шифровании новых экспортов. Старые зашифрованные .stbackup остаются импортируемыми с паролем, старые незашифрованные JSON также поддерживаются.
- Время нажатия кнопок и фактические границы сна хранить отдельно. Не подменять фактические данные кнопочными отметками.
- Недоступные HealthKit/Screen Time/датчиковые значения не моделировать и не подставлять нулями. Ручные данные явно маркировать.
- Корреляции и физиологические отклонения описывать нейтрально, не выдавая их за диагноз или причинно-следственную связь.
- Личные рекорды ограничены четырьмя согласованными показателями: максимальная продолжительность сна, максимальная эффективность при достаточном покрытии, минимальная подтверждённая задержка засыпания и максимальная серия записей. Не добавлять рекорды SleepScore/пробуждений и отдельную историю их обновлений. Сохранённые четыре лучших значения и даты не терять при удалении исходной ночи.

## Этапы реализации
Версия 0.5: реализовано постоянное хранение заметок и оценок самочувствия по ночным сессиям. Версия 0.6: добавлена подробная карточка ночи и редактируемый утренний отчёт на основе реально сохранённых данных. Версия 0.7: добавлен календарь дневника с индикацией только сохранённых оценок самочувствия и переходом к карточке выбранной ночи. Следующие этапы — подключение HealthKit, аудионаблюдение, аналитика и резервное копирование согласно архитектуре.


Версия 0.8: добавлена недельная и месячная аналитика на основе фактически сохранённых сессий и оценок. Версия 0.9: добавлено сравнение двух произвольно выбранных ночей без изменения исходных записей и без подстановки отсутствующих показателей.

## Облачная сборка v0.11.1
- Для сборки iOS без собственного Mac используется GitHub Actions на macOS runner.
- Перед выпуском IPA обязательны `flutter analyze` и `flutter test`.
- Артефакт создаётся без Apple-подписи; дальнейшая установка выполняется через AltStore.
- Bundle ID `ru.sleeptracker.app` сохраняется.


## Резервное копирование v0.12.0
- Формат файла: JSON, идентификатор `sleep_tracker_backup`, версия формата 1.
- В копию включаются все таблицы действующей SQLite schema v3.
- Экспорт передаётся системным меню iOS; пользователь сам выбирает расположение, включая приложение «Файлы».
- Импорт поддерживает полную замену и безопасное объединение. При конфликте ID в режиме объединения сохраняется локальная запись.
- Импорт валидируется и выполняется в одной транзакции.
- Аудиофайлы, отчёты и настройки, которых ещё нет в текущей схеме, не заявляются как включённые в резервную копию.
