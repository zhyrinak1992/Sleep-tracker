# Яндекс Smart Home — статус реализации

Дата обновления: 26.11.2026.

## Реализовано в исходниках
- OAuth Device Authorization Flow: запрос кода, подтверждение пользователем, polling с интервалом Яндекса и обработкой состояний ожидания/истечения/отказа.
- Хранение access token и refresh token в iOS Keychain через flutter_secure_storage с ThisDeviceOnly; токены не входят в SQLite и резервные копии.
- Обновление access token при HTTP 401. Токены очищаются только при HTTP 400 invalid_grant; прочие ошибки не должны приводить к потере сохранённых credentials.
- Read-only доступ к Яндекс Smart Home: GET списка комнат/устройств и GET состояния выбранного устройства; только scope iot:view, без управления устройствами.
- Фильтрация фактических retrievable-свойств температуры и влажности; сохранение реального last_updated, единиц, датчика, комнаты, источника и связанной активной ночной сессии.
- Дедупликация измерений по датчику, типу показателя и timestamp; отсутствие данных не заменяется нулём.
- Выбор датчика, отображение его комнаты, ручное обновление показаний и отключение интеграции.
- Автоматический опрос с минимальным интервалом 15 минут при подключённом аккаунте, выбранном датчике и активной ночной сессии. В фоне опрос best-effort и зависит от фонового аудионаблюдения и ограничений iOS.
- Аналитика за 30 дней: min/mean/max, стандартное отклонение, последнее значение, число точек, покрытие 15-минутного интервала и график с разрывами при больших пропусках.
- В карточке отдельной ночи — фактические сводки температуры и влажности.

## Ещё не завершено
- Реальное сквозное тестирование авторизации и обновления токена на аккаунте Яндекса с физического iPhone.
- Проверка фактической совместимости конкретных датчиков и стабильности их last_updated.
- Гарантированный сбор при заблокированном экране/закрытом приложении: iOS не гарантирует выполнение Dart Timer; текущий фоновый опрос остаётся best-effort.
- Отдельный выбор комнаты как самостоятельного фильтра: сейчас комната отображается у найденного датчика, а пользователь выбирает сам датчик.
- Полный сетевой OAuth/API контракт не проверяется автоматически в CI реальными запросами; unit-тестируется политика обработки ошибки refresh token.

## Важное

Яндекс API предоставляет текущее состояние устройства и timestamp последнего обновления, а не гарантированный архив телеметрии. Сбор зависит от доступности датчика и запуска приложения. Интеграция не управляет устройствами и не запрашивает iot:control.
