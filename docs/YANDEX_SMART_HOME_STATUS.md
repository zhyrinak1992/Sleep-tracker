# Яндекс Smart Home — статус реализации

Дата обновления: 22.11.2026.

## Реализовано в исходниках
- Read-only HTTP client для `GET /v1.0/user/info` и `GET /v1.0/devices/{device_id}`.
- Фильтрация доступных к чтению `temperature` и `humidity` properties.
- Сохранение access token в iOS Keychain через flutter_secure_storage с атрибутом first-unlock-this-device-only.
- Экран настроек: ввод готового OAuth access token, проверка доступа, список найденных сенсоров, выбор одного датчика, ручное получение текущих показаний и отключение.
- SQLite `climate_samples`, миграция схемы v6, экспорт и восстановление этих записей.
- Сохранение фактического времени `last_updated`; отсутствие/неактуальность данных не заменяется нулём.
- Автоматический опрос раз в 15 минут, только пока приложение активно, и при возвращении в приложение. Если есть активная сессия сна, sample связывается с ней.
- Карточка в разделе «Анализ»: фактические min/mean/max, последнее значение и число точек за 30 дней.
- Нет методов POST/DELETE и нет scope `iot:control`.

## Ещё не завершено
- Интерактивный OAuth authorization-code flow с callback URL и безопасным refresh token.
- Сбор измерений при заблокированном экране/полностью закрытом приложении. iOS не гарантирует выполнение Dart Timer в фоне; для этого нужен отдельный BGTask/background refresh механизм, который также остаётся best-effort.
- График климатической истории и утренние min/max/mean/last/coverage для выбранной ночи.
- Физическое тестирование на датчиках разных производителей и на iPhone.

## Важное
Текущий экран принимает уже полученный OAuth access token вручную. Это промежуточный технический интерфейс, не финальный UX авторизации. Не вставлять токен в GitHub issues, исходники, чаты или резервные копии.
