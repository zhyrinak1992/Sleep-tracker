# Подключение Яндекс Умного дома в Sleep Tracker

## Принцип работы
Интеграция использует пользовательский REST API Яндекс Умного дома только для чтения:
- `GET /v1.0/user/info` — список комнат и устройств;
- `GET /v1.0/devices/{device_id}` — текущее состояние выбранного устройства.

В коде отсутствуют POST/DELETE запросы к API Яндекса. Не запрашивать scope `iot:control`; необходим только `iot:view`.

## Поддерживаемые измерения
Приложение ищет в массиве `properties` только свойства с `retrievable: true` и `parameters.instance` равным:
- `temperature`;
- `humidity`.

Сохраняется `state.value` вместе с `last_updated`, ID/названием устройства, комнатой, единицей измерения и источником. Время измерения берётся из `last_updated`, а не из времени получения HTTP-ответа. Если свойство отсутствует, не retrievable, не имеет значения или timestamp, измерение не создаётся.

## OAuth и секреты
1. Зарегистрировать отдельное OAuth-приложение Яндекса для Sleep Tracker в кабинете разработчика Яндекса.
2. Запросить только доступ к данным умного дома `iot:view`; не запрашивать `iot:control`.
3. Получить OAuth access token по официальному OAuth-процессу Яндекса.
4. Ввести токен в настройках приложения. Токен сохраняется через `flutter_secure_storage` в iOS Keychain с доступностью ThisDeviceOnly.
5. Токен не попадает в SQLite, резервные копии, логи или репозиторий.
6. При HTTP 401/403 пользователь должен повторно пройти авторизацию; приложение удаляет недействительный токен после неуспешной проверки первоначального подключения.

На текущем этапе экран использует ручной ввод уже полученного access token. Интерактивный OAuth authorization-code flow и безопасное обновление refresh token ещё не реализованы. Не считать подключение production-ready до завершения этого этапа.

## Ограничения
- API отдаёт актуальное состояние устройства и timestamp последнего обновления, а не гарантированный архив телеметрии.
- Sleep Tracker сохраняет только новые фактические timestamps в локальной таблице `climate_samples`.
- Не создавать искусственные точки, нули или интерполированные значения.
- Текущая кнопка «Получить актуальные показания» запускает разовый опрос. Фоновый периодический сбор и график временного ряда ещё предстоит реализовать.
- iOS может ограничивать фоновые задачи. Частоту и полноту сбора нельзя обещать без тестирования на физическом iPhone.
- Некоторые устройства могут не предоставлять температуру/влажность через свойства API, даже если их приложение-производитель показывает эти значения.
