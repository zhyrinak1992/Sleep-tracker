# Сохранение истории звуковых событий

Дата: 22 ноября 2026 года. Версия приложения: 0.21.0+22.

## Правило хранения
- Аудиофрагмент хранится не более 7 дней.
- По истечении срока удаляется физический аудиофайл, а `audio_events.file_path` устанавливается в NULL.
- Запись события, категория, уверенность классификации, время, длительность и признак ручной корректировки остаются в SQLite без ограничения срока в рамках истории сна.
- Пользовательское удаление отдельного события остаётся отдельным действием и удаляет само событие.

## Миграция SQLite v8
- Пересоздаёт таблицу `audio_events` с nullable `file_path`.
- Переносит все существующие записи без изменения ID и классификации.
- Сохраняет внешний ключ к ночной сессии и индекс срока хранения.

## Резервные копии v4
- В архив включаются все события, в том числе события без сохранённого аудиофайла.
- Для действующих аудиофайлов добавляются вложения Base64.
- Событие с `file_path = null` является корректным историческим событием и не считается повреждённым архивом.
- Если путь к ещё действующему файлу есть, но сам файл отсутствует, экспорт останавливается, чтобы не скрывать потерю аудиоданных.
- Импорт форматов v1, v2 и v3 остаётся поддержанным.

## Ограничение проверки
Изменения внесены в исходники. Автоматическая сборка/анализ и тесты CI должны пройти до статуса «проверено»; физическое тестирование iPhone остаётся отдельным этапом.
